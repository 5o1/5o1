## Notes

- The original `github-readme-stats` repository currently recommends considering newer successors or the Action-based approach; check its README before deploying a new instance.
- Dynamic services are convenient, while GitHub Actions that commit SVG files are usually more stable for a personal profile.
- For the `5o1` profile, the current setup uses Skill Icons, Profile Summary Cards, GitHub Stats, and Profile Trophy.
